# AI Document Assistant

An AI-powered document question-answering application built with Python and FastAPI. Upload a PDF, ask questions about its content, and receive natural-language answers generated by a local LLM using Gemma through Ollama.

## Features

- Upload PDF documents through a REST API.
- Extract text from PDFs using PyMuPDF.
- Ask questions about uploaded documents.
- Retrieve relevant paragraphs using keyword matching.
- Generate natural-language answers using Gemma through Ollama.
- Validate request data using Pydantic.
- Handle invalid PDFs and missing documents.
- Explore and test API endpoints using Swagger UI.

## Tech Stack

- **Language:** Python
- **API Framework:** FastAPI
- **Large Language Model:** Gemma 2B
- **LLM Runtime:** Ollama
- **PDF Processing:** PyMuPDF
- **HTTP Client:** HTTPX
- **Data Validation:** Pydantic
- **ASGI Server:** Uvicorn
- **Dependency Management:** uv
- **Version Control:** Git and GitHub

## How It Works

1. Upload a PDF document through the API.
2. Extract text from the PDF using PyMuPDF.
3. Submit a question about the document.
4. Retrieve relevant paragraphs using keyword matching.
5. Send the retrieved context and question to Gemma through Ollama.
6. Return the generated answer as a JSON response.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/uday-Tharlada-0/AI_DOCUMENT_ASSISTANT.git
cd AI_DOCUMENT_ASSISTANT
```

### 2. Install Dependencies

Install the project's dependencies using uv:

```bash
uv sync
```

### 3. Download the Gemma Model

If you have not already downloaded the model, run:

```bash
ollama pull gemma:2b
```

### 4. Configure Ollama

Ensure that the Ollama server is running and accessible from the environment where the FastAPI application runs.

The application uses the Ollama generation API:

```text
http://<ollama-host>:11434/api/generate
```

Replace `<ollama-host>` with the appropriate hostname or IP address for your environment.

Configure the `OLLAMA_URL` environment variable to use this endpoint. If the application runs in WSL and Ollama runs on Windows, use the working Windows host address for your setup.

Keep the Ollama server accessible only to trusted systems.

### 5. Start the FastAPI Application

If `main.py` is in the project root, run:

```bash
uv run uvicorn main:app --reload
```

If your application uses a `src/` directory, use the import path appropriate for your package structure.

### 6. Open Swagger UI

Once the application starts, open:

http://127.0.0.1:8000/docs

Use the interactive API documentation to upload a PDF and ask questions about its content.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Check whether the application is running |
| POST | `/upload` | Upload a PDF and extract its text |
| POST | `/ask` | Ask a question about an uploaded document |

### Example Question Request

Endpoint: `POST /ask`

```json
{
  "filename": "Python and Java Study Notes.pdf",
  "question": "What is Python?"
}
```

The filename must match a document uploaded to the running application.

### Example Response

```json
{
  "question": "What is Python?",
  "answer": "Python is a high-level, general-purpose programming language known for its readable syntax."
}
```

The actual answer depends on the document content, the retrieved context, and the language model's response.

## Current Limitations

- Uploaded documents are stored in memory and are lost when the application restarts.
- Retrieval currently uses keyword matching rather than semantic search.
- Relevant information may be missed when the question uses different wording from the document.
- Answer quality depends on the retrieved context and the language model.
- Scanned PDFs without extractable text may require OCR.
- Authentication and persistent document storage have not yet been implemented.
